# Gloria Tumsifu Kasunzu — Portfolio

Portfolio personnel bilingue (français et anglais), développé en HTML/CSS/JavaScript sans dépendance de build.

## Aperçu local

`python -m http.server 8000` puis ouvrir `http://localhost:8000`.

## Direction artistique

- Noir : `#0e0e0e`
- Blanc : `#ffffff`
- Bordeaux : `#652936` (échantillonné de la référence approuvée)
- Typographie d'affichage : Wremena, fichiers WOFF locaux
- Texte : DM Sans

## Structure

- `index.html` : contenu et structure
- `styles.css` : mise en page responsive
- `script.js` : traduction FR/EN et filtres des projets
- `assets/` : polices locales et aperçus de créations Canva
- `tests/smoke.mjs` : vérifications structurelles
